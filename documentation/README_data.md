# Source data

The analyses use publicly available international databases from the International Association for the Evaluation of Educational Achievement.

The source databases are not redistributed in this repository.

The analysis uses public-use data from:

- ICILS 2023
- TIMSS 2023 Grade 8
- PIRLS 2021
- ICCS 2022

The R Markdown script identifies the official IEA data archives required to reproduce the analyses.

Users wishing to reproduce the results should obtain the relevant public-use databases directly from the IEA Data Repository and place them in the local data directories described in the analysis script.
